# compositor
reviewed: 9c58b36 2026-10-30  (full)

The neutral QML layer holds: every consumer goes through CompositorManager, every `supports` key read is declared by a backend, layer order comes only from LayerStack, and every RPC name, fact and state field the shell uses matches the daemon's Go. The problems are in the daemon's Go, first read in this review: the manager loses track of what is loaded on rarer paths (the saved monitor profile after a file stops loading, a module left full when included was left between sessions, a failed takeover showing no layer and no problem), the takeover's rules can be sidestepped (a stale check adopting without approval, a symlinked or git-tracked config claimed as ours but never released), sway's writer targets a fixed config path, and the sway and niri bind merges can lose or break binds. Earlier, still open: the daemon picks its compositor on its own.

## Contract
Holds: C1 (no `HyprlandManager.`/`SwayManager.`/`NiriManager.` outside the backends and the facade); C2 (every `supports` key read in QML, YAML, `x-needs`, the action table's `needs` and the Go is declared by at least one backend and read somewhere; absences match sway-backend.md/niri-backend.md's "Not:" lists); C3 (the daemon's `live()` needs facts naming its kind; release backoff 10 s → 5 min; in-session module emptying); C4 and the layer docs (unchanged since the last review). Daemon: `compositor.inputs` decoded strictly and every field the shell sends matches `manager.Facts`; every `compositor.state` field the QML reads exists; one goroutine, `enqueue` never blocks; paused binds left out, previews laid over a clone; writes only on change and atomic (`edit.Replace` → `fsx.WriteFile`, state and approvals too), niri validated first; `compositor.json` taken only for the same instance; `undoLive` counts only supported parts, skips `takesBack`; a blur-only change sends `blurLines`; the hold sets up and gives back nothing; approvals added only by `AllowTakeover`; status values as documented; cursortheme never touches a folder without its marker, swaps companions atomically, sets gsettings only where readable. Window look: offset 0 written by all three writers, empty shadow color by none, strength 0 gives alpha 0, GaussianShadow/SoftShadow sizes as documented. KDL and sway output with quotes, backslashes, newlines and min/max inputs accepted by `niri validate`. IPC clients: deadlines on every request, event streams closed through `context.AfterFunc`, reconnect after 2 s, untrusted JSON into typed structs. Takeover: release writes before it removes, backups by atomic rename; userconf include cycles end. Bind merge: a second merge is idempotent, backups before writes, the notUser check, an unknown kind refused.
