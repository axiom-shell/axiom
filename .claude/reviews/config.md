# config
reviewed: b519ddd 2026-10-31  (full)

The store, drafts and previews keep their contract on the paths taken daily: takeovers are held against outside edits, refused saves read back, writes are atomic. The weak spots are recovery and edit paths: over a config.json that didn't load, keeping the running config writes the defaults over the active snapshot; the settings page previews `x-takeover` switches (polkit, idle, locker) live before Save; a number box can commit typed text onto another setting.

## Contract
Holds: the shell reads only `$AXIOM_CONFIG`/`$AXIOM_SCHEMA`; a push applies on revision+1, else `config.get`; a broken file at the start runs on defaults with saves blocked and the file's takeovers kept; `holdTakeovers` holds, logs and writes back; a refused hello fails queued and later calls, a drop fails in-flight and queued; `commit` fills defaults, diffs, applies, sends `config.set`, and a refusal reads back (`hardResetConfig` → `saveRefused`); `ConfigOps.apply` copies only along each path; `DataDirs` as documented; `loadIfStale`; previews cleared on draft load, `x-applyOnSave` held (not `x-takeover`: filed); `Store.Replace` keeps takeovers; apply is keep → replace → save → drop, Revert skips keep; the active snapshot persists; i18n writes are atomic and the hook stops on unstaged language edits; forms translate their own text; settings-page S1–S12 (keys as strings, typing held, discard sizes, folding, columns, jumps, scroll memory, search debounce, `openSetting`); `x-showIf`/`x-enabledIf`/`x-enumShowIf`/`x-auto`/`x-inherit`/`x-beside`. Readers: no `??` fallback on their section (the rest are on arguments, map lookups or `x-inherit` nulls), only `BarsConfig.savedBars` reads `config`, no service but `FileManager` (filed). The only `config.set` is `ConfigManager.commit`'s, called only by `SettingsManager` and `ConfigDraft`; no UI reads `ConfigManager.config`/`.live`. `x-scope`: every command field `commands` (exec binds and hot corners through `x-scopeIf`), every monitor, path, folder, URL and account `machine`. Go tests of store, saved, share and `tst_SchemaLayout`/`tst_ColumnSplit`/`tst_SettingsSearch` pass.
