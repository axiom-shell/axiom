# Services (`qml/services/`)

Docs: `docs/dev/core/services-pattern.md` and the feature's doc. Public API per service: `docs/dev/generated/api/<Name>.md` (regenerated by `scripts/gen_docs.py`). Recipes: `/service`, `/launcher-command`.

- **Folders** are QML modules (`import qs.services.<folder>`): `core/` (config, theme, the daemon bridge and its funnels, secrets), `compositor/`, `session/` (lock, auth, greeter, idle, polkit), `system/` (desktop basics every user has), `ui/` (the shell's own surfaces and editors), `apps/` (optional features and integrations). A new service goes in the folder its domain fits, never directly in `qml/services/`.
- **Non-singletons** a service builds (`ConfigDraft`, `ConsumerRegistry`, `IpcTarget`, `GridEditor`, …) live beside their owner, are named for what they are (never `*Manager`), and their file comment names the owner.
- Expose readonly properties, signals and functions; private members start with `_`.
- **Polled data**: wrap a private `ConsumerRegistry`. Prefer polling in the daemon (a `topics.Source`, `docs/dev/backend/protocol.md` › Polled topics): pass the merged request to `BackendManager.acquire(topic, …)` while `_registry.active` (copy `TailscaleManager.qml`). Polled in QML: the shortest interval asked (with a floor), the Timer running only while `_registry.active`, the command through `CommandManager.run`.
- **IPC**: `property IpcTarget _ipc: IpcTarget { target: "…"; function x(): void {…} }` with typed parameters (copy `IdleManager.qml`); never `IpcHandler`. Add the target to the `docs/usage.md` IPC table. A service reached only by IPC is listed in `qml/shell.qml`'s `_services`.
- **Editors** own a `ConfigDraft` and their selection (`select*()`); pages never assign them.
- **Greeter mode** (`Paths.greeter`) runs data, never code: nothing writes config, generates or runs integrations, so a side effect reachable there checks `Paths.greeter` first. Only `GreetdManager` talks to greetd.
- **Locking**: only `LockManager.lock()` locks; in `quickshell` mode only PAM success (`AuthManager`) unlocks, never IPC.
- **Reload-surviving state**: `PersistentProperties` as a default child of the singleton (or of a `Scope` that is one); in a named property or under a plain QtObject it starts empty each reload. Small persisted state: `StateManager`.
- **Hyprland** calls are Lua (`hl.*`), sent only by the `Hyprland*` files, the only ones importing `Quickshell.Hyprland`; only `CompositorManager` uses `HyprlandManager`.
- **Launcher**: every provider returns the same row shape; `/config` never edits `Bars.items`, `Overlay.items` or `Menus`. A command toggling or running an action is a `_switch(…)` / `_action(…)` entry in `LauncherCommands.qml` (run through `ActionsManager`), a page opener `_page(…)`; others are full entries (`name`, `aliases`, `glyph`, `description: () => I18n.tr(…)`, `available`, `run(arg, value)`, …).
