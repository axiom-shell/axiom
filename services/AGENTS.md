# Services (`services/`)

One `pragma Singleton QtObject` per domain, named `*Manager`: state and every side effect (processes, dispatches, file writes, polling). Docs: `docs/dev/core/services-pattern.md`, plus the feature's doc in `docs/dev/features/`. Each service's public API: `docs/dev/generated/api/<Name>.md` (generated; rerun `scripts/gen_docs.py` after changing public members or an `IpcTarget`).

**Recipe:** `docs/recipes/service.md` / `docs/recipes/launcher-command.md`; verify with `scripts/dev/verify.sh`.

- Expose readonly properties, signals and functions; private members start with `_`. Don't shadow Quickshell singletons (`NetworkingManager`, not `Networking`). `check_structure.py` errors on a `FooManager.` reference with no file.
- **No new direct Quickshell.Io**: `Process`, `FileView`, `Socket`, `IpcHandler` and `Quickshell.execDetached` only in the files `scripts/quickshell-io-allowlist.json` lists (they're moving to the axiom daemon, in the order `docs/dev/backend/roadmap.md` sets). Run commands with `CommandManager.run`, read files with `FileManager.read`, keep small state in `StateManager`; a file to watch or write otherwise is a daemon method.
- **Polled data**: `acquire(owner, request)` / `release(owner)` wrapping a private `ConsumerRegistry`. Polled by axiom (preferred: a `topics.Source` in the daemon, `docs/dev/backend/protocol.md` › Polled topics), the merged request goes to `BackendManager.acquire(topic, …)` while `_registry.active` and the state comes from `<topic>.state` (copy `TailscaleManager.qml`); polled in QML, the interval is the shortest asked (with a floor), the Timer runs only while `_registry.active`, and the command goes through `CommandManager.run` (the recipe's skeleton). Requests come from config only.
- **IPC**: `property IpcTarget _ipc: IpcTarget { target: "…"; function x(): void { … } }` with typed returns (copy `IdleInhibitManager.qml`). An `IpcTarget` is an `IpcHandler` that also registers with axiom, so `axiom ipc` reaches it over the shell's connection; a bare `IpcHandler` is refused by `check_structure.py`; add the target to the `docs/usage.md` IPC table. A service reached only by IPC is created from `shell.qml`'s `_services`.
- Config writes only through `ConfigManager` / `SettingsManager` (root `AGENTS.md` › Services). Editors own a `ConfigDraft` and their selection (`select*()`).
- **Greeter** (`docs/dev/features/greeter-runtime.md`): it reads only the exported bundle (data, never code). In greeter mode (`Paths.greeter`) nothing writes config, generates or runs integrations, so a side effect reachable from it checks `Paths.greeter` first. Only `GreetdManager` talks to greetd.
- **Lockscreen** (`docs/dev/features/lockscreen.md`): `LockManager.lock()` is the only way to lock; in `quickshell` mode only PAM success (`AuthManager`) unlocks, never IPC. The surface keeps a fallback password field for a layout without one.
- State that must survive a QML reload: `PersistentProperties`; small persisted state: `StateManager` (`~/.local/state/axiom/ui/*.json`) or `Paths.userStatePath`, written atomically.
- Secrets only through `SecretsManager` (stdin, never argv or config.json).
- The compositor is reached through `CompositorManager` (`docs/dev/compositor/README.md`): its state, its events (`configReloaded`, `layersChanged`, …), workspace and window focus. Hyprland calls are Lua (`hl.*`), sent only by the `Hyprland*` services, the only files importing `Quickshell.Hyprland`; only the Hyprland-only features (gated on `CompositorManager.supports`) use `HyprlandManager` directly.
- **Launcher** (`docs/dev/features/launcher.md`): every provider returns the same row shape; `/config` can never edit `Bars` or `Overlay.items`. Commands are `LauncherCommands.qml` entries (`name`, `aliases`, `glyph`, `usage`, `description: () => I18n.tr(…)`, `available`, `status`, `options`, `run(arg, value)`); copy the `nightlight` entry.
